# Blurb

Linked Lunancy is an educational computer science game that aims to teach players about doubly and singly linked lists. Players start with understanding the basics of linked lists through touch and drag mechanics and moving the players with the arrow keys. They will then learn to identify different kinds of linked lists and things like prev, next, head, and tail. Eventually the player will apply what they learned in previous levels to then type out answers that will help them traverse the bridge. Linked Lunancy is also accompanied by cute visuals and music to make the game more dynamic and inviting to the player.

# Basic Instructions

The player will begin by following the instructions at the top of the screen and either click and drag a bridge tile to its correct position or move the player to the correct position using the arrow keys. After correctly answering 8 questions, the player will answer a new set of question types that will include correctly selecting if a question is a singly or doubly linked list. In the final level the player will type the correct line of code based on the question at the top of the screen
